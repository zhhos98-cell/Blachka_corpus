# Rudolf 1892 reference-lineage + installation-mobility pass 18 — 13 August 2026

## Purpose

The previous passes left two different kinds of unfinished work. Object anchors such as model 433 and model 345 were already strong, but their evidential status mixed metadata, inference and still-unseen images. The transport argument also had a Chicago 1893 damage episode that was analytically useful but still too easy to describe as an accident after carriage.

This pass separates those problems.

First, it distinguishes **metadata closure** from **image-level closure** for the two best field-reference/model cases. Second, it rereads Chicago as a genuine post-arrival mobility sequence. The most important result is that a model could pass through successful carriage, become installed, and then be set in motion again by the material architecture intended to keep it safe.

The strongest formulation after this pass is:

> **Arrival did not end mobility. A fragile object could enter a new movement regime when its supports, display furniture, building vibration and handling procedures changed. Transport history therefore continued through installation, repair and re-stabilization.**

A related source-critical rule should now be explicit:

> **A metadata crosswalk is not yet an image-level genealogy.**

No public map changes are made.

## 1. Model 433: metadata crosswalk is now strong enough to freeze, while the physical genealogy remains open

The existing working crosswalk for model 433 can be tightened without inflating its claim.

Harvard University Herbaria metadata independently identifies **GH 01676890** as *Hoffmannseggia glauca* (Ortega) Eifert, collected in **Arizona, Tempe?**, in **April 1892**, by **W. F. Ganong and R. Blaschka**. The Harvard record lists an image as available.

The model-side metadata identifies:

- model **433**;
- historical label: *Hoffmanseggia densiflora (Hoffmanseggia stricta)*;
- updated label: *Hoffmannseggia glauca* [syn. *H. densiflora*];
- shipment: **9th Shipment, January 1894**, model span 424–473.

The maker-side retrospective source `BLA-D01749 / 020:278` places 433 Hoffmannseggia among the smaller models Rudolf says he constructed himself, while describing much analytical-detail work as Leopold's.

These records now support a stable first-order statement: an April 1892 field reference remained at Harvard as a herbarium specimen while a related glass representation was later manufactured in Hosterwitz and shipped back to Harvard in January 1894.

The important restraint is equally clear. This does **not** yet prove that GH 01676890 was the sole physical template placed before Rudolf while making model 433. That stronger statement requires the specimen image and its annotations, the original model-label image, and ideally an intermediate drawing or correspondence statement. Until then the correct category remains **reference-lineage divergence**.

This distinction helps the larger transport argument. The field plant did not simply travel to become glass. Observation generated descendants in different media, and those descendants acquired different storage and mobility histories.

## 2. Model 345: shipment placement can be closed more tightly than the drawing genealogy

Pass 14 already isolated model 345, *Abronia umbellata*, as the strongest seventh-shipment American-plant candidate. The present pass checks the actual shipment-list continuity rather than relying only on a model-range reconstruction.

The annotated Harvard shipment list in 05B is explicit:

- `7th. Shipment, Feb. 1893.` begins at model **312**;
- within that same uninterrupted list appears **345. Abronia umbellata, Lam.**;
- the heading `8th. Shipment, July 1893.` appears only after model **373**, with model **374** beginning the next shipment.

The placement of 345 inside the February 1893 seventh shipment is therefore direct, not merely inferred from neighboring correspondence.

The field side is also direct. In `BLA-D00797 / 017:151`, in the late-April 1892 southern California sequence, Rudolf notices the **violet heads of *Abronia umbellata*** in the landscape among the western vegetation.

The Corning/Rakow finding aid supplies a third object type. Its botanical preparatory-drawing subseries, described as containing many Rudolf drawings based on the 1892 and 1895 field trips, includes **`Abronia umbellata, 1892 or 1895`**.

Chronology supplies a useful constraint. If this particular drawing is the preparatory drawing used for model 345, it must relate to the 1892 rather than the 1895 trip because model 345 had already left Hosterwitz in February 1893. But chronology does not identify the drawing's function by itself.

The evidential ladder is therefore:

1. **closed:** Rudolf encountered *Abronia umbellata* during the 1892 western journey;
2. **closed:** model 345 is *Abronia umbellata* and belongs to the seventh shipment of February 1893;
3. **closed:** a Corning preparatory drawing titled *Abronia umbellata* is catalogued as `1892 or 1895`;
4. **open:** whether that exact drawing is the drawing used to make model 345.

This is a better object anchor precisely because the unresolved step is small and visible.

## 3. Chicago 1893 is not merely a damage anecdote

The Chicago sequence should now be read as a post-arrival transport experiment.

`BLA-D00145` reports that the models reached Chicago and were set up with only slight breakage after carriage. The exact carrier-treatment wording is OCR-unsafe, but the broad condition report is clear enough: physical transport had apparently succeeded.

The situation changed after installation.

In the letter dated **28 May 1893**, `BLA-D00149 / 015:149`, Goodale describes arriving at the Glass Flowers display in the Liberal Arts / Manufactures Building and discovering that the **velvet on which the models had been thought safe had acted as a means of moving them in all directions**. The following OCR is imperfect, but multiple copies agree on the operational result: objects were displaced or huddled and many pieces were broken in connection with vibration in the building.

This reverses the normal temporal expectation. The dangerous phase was no longer the railway, steamer or express transfer. A support material selected for the static exhibition state became unsafe under a different vibration environment.

The causal chain is therefore:

`successful carriage → installation on velvet → building vibration → displacement → collision/breakage`.

That is a transport problem in a new object state.

## 4. Goodale then creates another reconstruction cycle

`BLA-D00149–00150` continues beyond the discovery of damage. Goodale creates a curtained-off work area and begins repairing the display. The stable operational elements across OCR variants are unusually useful:

- fractures are repaired;
- the models are remounted;
- labels / backing are renewed or reset;
- the case is restored;
- the reconstructed arrangement is deliberately subjected to shaking/jarring as a test;
- the case is then reopened to visitors.

The exact wording of several materials and damaged parts still requires the manuscript image. The sequence itself is secure.

This gives a second version of the `serial reconstruction` mechanism established in pass 16. At Harvard, unpacking converted a transport assemblage into an installed museum object. At Chicago, installation itself failed and forced the object back into a workshop-like state:

`installed exhibit → destabilized fragments → repair workspace → remounted object → tested installation → exhibit`.

The museum/exhibition endpoint is therefore reversible. A displayed object can re-enter handling, repair and testing.

## 5. Support materials have state-dependent affordances

The Chicago case makes the material mechanism more precise than a general claim about fragility.

A support is safe only relative to a particular movement environment. The same velvet that seemed appropriate as a static display substrate could allow lateral movement when the building vibrated. Likewise, pass 16 showed that a shipping case able to survive large external shocks did not protect a leaf from a ring, sleeve or shawl during unpacking.

The shared mechanism is scale and state dependence:

`safe in state A ≠ safe in state B`.

For the Blaschka models this means we should stop treating `packing`, `unpacking`, `mounting` and `display` as simple chronological labels. Each is a **material regime** with different supports, permissible movements, hazards and skills.

The revised state sequence is now:

`manufactured → transport-supported → freight → customs-controlled → inspected → unpacked → transport support removed → mounted/labelled → installed → possibly displaced/broken → repaired/remounted → stress-tested → re-exhibited`.

A single glass flower can cross several of these states without changing city.

## 6. Snow's $106.97 bill belongs to a different clock: settlement

`BLA-D00140 / 015:140` remains too corrupt for a publication transcription, but one result can be frozen now. Goodale refers to **E. A. Snow's bill for $106.97** and describes it as aggregating multiple classes of expense connected with the cases.

Across the OCR variants the visible categories include:

- German railway charges;
- freight by ocean and Sound steamers;
- an additional freight / transfer line whose place wording is presently corrupt;
- Custom House expenses;
- carriage for the inspector;
- Snow's commission.

The exact case wording and the corrupt place-name line remain open. The accounting structure is already clear. Several geographically and institutionally distinct operations become one receiving-side bill.

This supports the multi-clock model in the current handoff. `arrival` and `settlement` are different events. A case can reach the museum while its movement is still being converted into an auditable financial object.

## 7. Relation to the article argument

The current transport thesis is becoming more concrete if organized around **state changes and descendants**, rather than around a single continuous route.

The 1892 field side supplies representational splitting:

`plant encounter → memory/drawing/specimen/seed/living material → uneven return routes → later model`.

The finished-model side supplies logistical state changes:

`glass object → temporary support → freight assemblage → customs object → museum object → exhibition object → damaged object → repaired/tested object`.

These processes are related but not identical. The first generates multiple descendants from a field reference. The second repeatedly changes the operational identity of a finished object so that different actors can move, inspect, account for, install or repair it.

This lets the paper make a stronger first-order claim than `transport mattered`:

> **Transport worked by changing what counted as the movable object. Plants were decomposed into portable references; glass models were temporarily rebuilt into freight; arrival required another reconstruction; installation could destabilize the object and initiate the cycle again.**

The empirical advantage of the Blaschka archive is that those transitions are often visible at the level of individual models, case marks, support materials, bills and named handlers.
