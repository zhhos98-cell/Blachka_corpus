# Temporary image test

The current GitHub Pages build temporarily includes a three-image visual index and a page-local jump hub to test how image-led navigation works with the editorial layout.

The test images are loaded remotely from Wikimedia Commons and are not stored as repository assets. All three are CC0:

- Harvard Museum of Comparative Zoology sea cucumber model, photograph by Daderot
- Natural History Museum, London octopus model, photograph by Vassil
- Grant Museum of Zoology Blaschka model, photograph by Vassil

This file exists only to make the temporary prototype easy to identify and remove after review.
