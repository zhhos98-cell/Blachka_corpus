# Generated structural inventories

Files in this directory are deterministic audit outputs. Do not hand-edit them or treat them as evidence-bearing research records.

- `schema-family-profile.json` — generated by `scripts/audit-json-schema-families.py`.
- `status-vocabulary-inventory.json` — generated by `scripts/audit-status-vocabularies.py`.
- `field-semantic-role-map.json` — generated by `scripts/audit-field-semantics.py`.
- `cross-register-duplication-index.json` — generated by `scripts/audit-cross-register-duplication.py`.
- `auction-canonical-sync-audit.json` — generated by `scripts/audit-auction-canonical-sync.py`.

The authoritative historical claims remain in the Source/Auction registers and other canonical research files. Re-run the relevant generating script when the public JSON structure changes. Audit outputs may identify review targets, but they never authorize automatic edits to canonical evidence.
