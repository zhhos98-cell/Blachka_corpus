# Generated structural inventories

Files in this directory are deterministic audit outputs. Do not hand-edit them or treat them as evidence-bearing research records.

- `schema-family-profile.json` is generated by `scripts/audit-json-schema-families.py`.
- `status-vocabulary-inventory.json` is generated by `scripts/audit-status-vocabularies.py`.

The authoritative historical claims remain in the Source/Auction registers and other canonical research files. Re-run the generating script when the public JSON structure changes.
