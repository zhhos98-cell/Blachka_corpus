# Generated structural inventories

Files in this directory are deterministic audit or maintenance outputs. Do not hand-edit them or treat them as evidence-bearing research records.

- `schema-family-profile.json` — generated by `scripts/audit-json-schema-families.py`.
- `status-vocabulary-inventory.json` — generated by `scripts/audit-status-vocabularies.py`.
- `field-semantic-role-map.json` — generated by `scripts/audit-field-semantics.py`.
- `cross-register-duplication-index.json` — generated by `scripts/audit-cross-register-duplication.py`.
- `auction-canonical-sync-audit.json` — generated by `scripts/audit-auction-canonical-sync.py`.
- `source-authority-crosswalk.json` — generated by `scripts/build-source-authority-crosswalk.py`; exact locators become derived nodes with occurrence edges back to their Source/Auction files and field paths.

The authoritative historical claims remain in the Source/Auction registers and other canonical research files. Re-run the relevant generating script when the public JSON structure changes. Generated outputs may identify review or navigation targets, but they never authorize automatic edits to canonical evidence.
