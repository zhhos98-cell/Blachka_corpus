Accessibility

Using the site

The site is designed for keyboard use, screen readers, browser zoom, touch input and reduced-motion or increased-contrast preferences. This is an implementation target, not a formal conformance certification.

Keyboard and structure

A “Skip to content” link is available as the first keyboard target. Navigation, search, filters and case links are intended to remain keyboard operable and visibly focusable. Pages use headings, landmarks and labelled form controls so the reading order does not depend on the visual layout.

Motion, contrast and zoom

The site avoids automatic image changes and decorative page-entry animation. Reduced-motion preferences also suppress remaining smooth scrolling and small hover transitions. Increased-contrast and forced-colour modes receive stronger focus and border treatment. Text and citations are allowed to reflow under browser zoom.

Images

Informative images have alternative text. Research figures connect images with captions where possible, and selected figures offer an optional visible image description. Decorative images are hidden from assistive technology.

Historical scans and collection photographs can contain details that are difficult to describe exhaustively. Where an image carries evidence, the surrounding text should also state the documentary point.

Interactive maps

The collection and 1892 journey maps are supplementary interfaces. Institution and route information is also presented as text or indexed controls outside the map where practical. Map markers and sketchbook-match markers remain keyboard reachable.

Known limits

  • Third-party museum, archive and image-hosting pages are outside this project’s accessibility control.
  • Some older image records still have concise descriptions.
  • Interactive maps remain more demanding than the text indexes that accompany them.

Report a problem

If a control cannot be reached, text overlaps at zoom, an image lacks a useful description, or a screen reader announces something incorrectly, email zhhos98@gmail.com with the page, device or browser, and what happened.
