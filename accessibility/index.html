Accessibility

Using the site

The project aims to make its research usable with keyboards, screen readers, browser zoom, touch input and reduced-motion or increased-contrast system preferences. This is an implementation target, not a formal conformance certification.

Current accessibility approach

The site is being developed toward WCAG 2.2 Level AA where practical. Navigation, search controls, case links, bibliography controls and source filters are intended to remain keyboard operable and visibly focusable. The site also uses semantic headings and landmarks, labelled form controls, text alternatives for informative images, and descriptive relationships for interactive case and family-person previews.

Keyboard and focus

A “Skip to content” link is available as the first keyboard focus target. Focus indicators are intentionally stronger than the normal visual styling. Hash links and keyboard-focused content are given scroll clearance so that site navigation should not obscure the focused target.

Motion, contrast and zoom

If your operating system requests reduced motion, page transitions, hover movement, flipping effects, automatic hero-image changes and smooth scrolling are suppressed. Increased-contrast and forced-colour modes receive simplified surfaces and stronger borders. Text and long citations are allowed to reflow and wrap under browser zoom instead of depending on a fixed desktop width.

Images and image descriptions

Informative images have alternative text. Where an image sits inside a research figure, the image is also programmatically connected to its caption. Key figures expose an optional Image description disclosure beneath the image, comparable to the alt-description affordance used by social platforms: it lets any reader open the visual description without forcing that prose into the main narrative.

The rotating homepage hero updates its alternative text and description with the active image, and includes a pause control. Decorative thumbnails are hidden from assistive technology. Some archival scans, historic documents and third-party collection images are visually complex; where the image itself carries evidence, the surrounding text should state the relevant documentary point rather than requiring visual inspection alone.

Known limits

  • Some complex provenance diagrams may still benefit from fuller text equivalents.
  • Third-party museum, archive and image-hosting pages are outside this project’s accessibility control.
  • Older image records may have concise descriptions while fuller object-level descriptions are still being written.
  • The site is under active revision, so keyboard, reflow and screen-reader behaviour may occasionally regress when a new research module is added.

Report an accessibility problem

If a control cannot be reached, text overlaps at zoom, an image lacks a useful description, or a screen reader announces something incorrectly, email zhhos98@gmail.com and include the page, device/browser and what happened.
