# Retired UI layers · 11 August 2026

These files were moved from the repository root after an active-reference audit found no public runtime consumers. They are retained for one release cycle as implementation provenance and rollback material.

They include historical consolidated bundles, constituent CSS passes, superseded map/visual scripts, and the old CSS bundle audit script. Their presence here does not make them public dependencies.

Do not restore individual files by filename alone. If a regression requires recovery, compare the current page-family CSS/JS against the archived layer and promote only the specific behavior that is still required.
