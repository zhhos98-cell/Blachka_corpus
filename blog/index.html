Project log

Building the first documentary chains

The first version of this site is testing a simple question: how far can a surviving collection be followed back through museum records, shipments, accounts and workshop correspondence, and then forward again?

Liverpool is the first public sample. The current chain reaches from an 1887 workshop sequence to later evidence for the surviving collection, while leaving the object-level gap visible.
